# C Course

XDU C/C++ 课程学习、数据结构、算法题、系统课程和课程项目。

## 目录结构

```text
01-c-basics/                  C/C++ 基础练习
02-data-structures/           数据结构
03-algorithms/                算法课程内容
04-operating-systems/         操作系统相关实验
05-computer-organization/     计算机组成原理
06-database-er/               ER 建模练习
practice/oj/                  按题源分类的在线判题练习
projects/                     独立课程项目
```

## 编译单个文件

```powershell
g++ -std=c++17 -Wall -Wextra path\to\source.cpp -o build\program.exe
build\program.exe
```

具体项目的编译和运行方式见对应目录中的 `README.md`。
